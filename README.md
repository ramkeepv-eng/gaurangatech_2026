# Gauranga Technologies — Website (HTML / CSS / JS)
Open `index.html` in a browser. No build step.
- `css/styles.css` — Gauranga Design System tokens (rust #9C3824, saffron #F0A428, Archivo + IBM Plex Sans), layout, animations.
- `js/main.js` — all content (SOL, FAM, PROD, CASES, ROLES, OFFICES, CLIENTS, QUOTES), router, carousel banners, scroll reveals, filters, forms.
- `images/` — logos; real photos (POLARIX, INTIG, founders, ISO); `site-*` images taken from the existing website pages; `gen-*`, `prod-*`, `studio-*` are AI-generated representative images — replace with real photos using the same file names.
Forms are front-end only; connect them to your backend before launch.
